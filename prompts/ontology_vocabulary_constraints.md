# Ontology Vocabulary Constraints

Use only these local names from `Clothing_Ontology.ttl`.

## Material

- `Cotton`
- `Wool`
- `Silk`
- `Polyester`
- `Nylon`
- `Denim`
- `Leather`
- `Linen`

## FormalityLevel

- `CasualLevel`
- `SmartCasualLevel`
- `BusinessCasualLevel`
- `FormalLevel`

## Season

- `Spring`
- `Summer`
- `Autumn`
- `Winter`

When product text supports a material that is not listed here, return `null` instead of creating a new value.
